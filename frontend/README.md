# Frontend (React + TypeScript + Vite)

The frontend application provides the user interface for:
- User registration, sign-in, and space switching (Phase 1).
- Document streaming uploads and status chips (Phase 2).
- Tags, status triage, notes, and the multi-page viewer (Phase 4).
- Full-text keyword search and result highlighting (Phase 5).
- Grounded conversational Q&A with clickable citations (Phase 6).

## Stack
- React 19 / TypeScript
- Vite
- Tailwind CSS or modern CSS
